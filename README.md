# SmartWinnr Admin Dashboard

A comprehensive web-based administration panel designed for visualizing sales analytics and managing user access controls. This application utilizes the MEAN stack (MongoDB, Express.js, Angular, Node.js) to deliver a responsive, secure, and data-driven interface.

## Project Overview

The SmartWinnr Admin Dashboard serves as a central hub for administrators and managers to monitor key performance indicators (KPIs) and handle user lifecycle management. It features a secure authentication system using JSON Web Tokens (JWT), real-time data visualization through Chart.js, and role-based access control.

### Key Features

* **Secure Authentication:** Token-based authentication system utilizing JWT stored in local storage.
* **Interactive Dashboard:** Visual analytics including line charts for revenue trends and bar charts for closed deals.
* **User Management:** Administrative interface to view registered users and revoke access (delete users).
* **Role-Based UI:** distinct visual indicators for Administrators, Managers, and Sales Representatives.
* **Resilient Architecture:** Frontend gracefully handles API failures by falling back to cached or mock data to ensure UI stability.
* **Data Seeding:** Automated scripts to populate the database with initial users and demo analytics data.

## Technology Stack

* **Frontend:** Angular 19+, Chart.js, Bootstrap 5
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JSON Web Tokens (JWT), Bcrypt.js
* **Tools:** Postman (API Testing), Mongoose (ODM)

## Prerequisites

Ensure the following software is installed on your local machine:

* Node.js (v18 or higher)
* npm (Node Package Manager)
* MongoDB (Running locally or a cloud connection string)
* Angular CLI (`npm install -g @angular/cli`)

## Installation and Setup

### 1. Clone the Repository

```bash
git clone <repository-url>
cd smartwinnr-assignment

```

### 2. Backend Configuration

Navigate to the backend directory and install dependencies.

```bash
cd backend
npm install

```

Create a `.env` file in the `backend` root directory with the following configuration:

```env
NODE_ENV=development
PORT=5000
MONGO_URI=mongodb://localhost:27017/smartwinnr_db
JWT_SECRET=your_secure_secret_key_here

```

**Database Seeding:**
Populate your database with initial users and analytics data. This script will clear existing data and insert default admin and user accounts.

```bash
node seeder.js

```

**Start the Server:**

```bash
npm run dev

```

The server will start on `http://localhost:5000`.

### 3. Frontend Configuration

Open a new terminal, navigate to the frontend directory, and install dependencies.

```bash
cd ../frontend
npm install

```

**Start the Angular Application:**

```bash
ng serve

```

The application will run on `http://localhost:4200`.

## API Documentation

The backend exposes a RESTful API. All protected endpoints require a valid Bearer Token in the `Authorization` header.

### Authentication

**Login**

* **Endpoint:** `POST /api/auth/login`
* **Description:** Authenticates a user and returns a JWT.
* **Body:**
```json
{
  "email": "admin@smartwinnr.com",
  "password": "password123"
}

```


* **Response:** JSON object containing user profile and `token`.

**Logout**

* **Endpoint:** `POST /api/auth/logout`
* **Description:** Logs the logout event on the server side.

### Analytics (Protected)

**Get Dashboard Stats**

* **Endpoint:** `GET /api/analytics/dashboard`
* **Headers:** `Authorization: Bearer <token>`
* **Description:** Retrieves aggregated data for summary cards, revenue charts, and deal metrics.

### User Management (Protected)

**Get All Users**

* **Endpoint:** `GET /api/auth/users`
* **Headers:** `Authorization: Bearer <token>`
* **Description:** Retrieves a list of all registered users (passwords excluded).

**Delete User**

* **Endpoint:** `DELETE /api/auth/users/:id`
* **Headers:** `Authorization: Bearer <token>`
* **Description:** Permanently removes a user from the database.
